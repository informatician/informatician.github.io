Weighted scoring matrix

Allocate weights across criteria, score each option, and see what is actually driving the ranking. Scales to any number of criteria and options.

1

The decision

State it as a question with a real answer.

2

Criteria

What the choice actually turns on. Split anything that hides two different things, since "growth" often means both skill and earnings, and they can point opposite ways.

3

Options

The alternatives on the table. Include the status quo as an option, since leaving it out quietly treats it as free.

4

Weights and scores

Allocate 100 points across the criteria first, before scoring anything. Weights set after the scores tend to bend toward the answer already preferred, so lock them in and then use blind scoring to keep them out of view.

5

Result

Nothing is stored in the browser. Save to a file to keep a decision, and load it back to carry on.
